## 三、三方渲染與編碼（本機限制）

本機 `D:\MacauSplat\engines\ffmpeg\ffmpeg.exe` 是 `--disable-libx264` 的建置，
而 HyperFrames 的 MP4 收尾固定帶 `-x264-params` → **`hyperframes render` 的編碼階段必定失敗**
（已實測：畫面擷取 6192/6192 完成後，encode 階段以 `Unrecognized option 'x264-params'` 收場）。

因此流程改為：

1. `npx --yes hyperframes@0.7.99 render -q high -f 30 --video-frame-format png --format png-sequence` → 6192 張 PNG
2. `tools/encode.py` 依序探測 **`h264_nvenc` → `h264_mf` → `libopenh264`**，本機使用 **`h264_nvenc`**（RTX 5070 Laptop）
   並以 `-pix_fmt yuv420p`、`-c:a copy` 直接複製 `assets/audio/mix.m4a`（避免二次編碼推高真實峰值）
