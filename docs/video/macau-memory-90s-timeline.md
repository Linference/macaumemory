## 已知取捨／不滿意處

1. **段⑥ 字幕寫「GPS 精确定位」，但畫面演示的是手動定位。** 依分鏡「逐字使用」照登；若要在畫面上也顯示 GPS 流程，需另錄一次（實測機無 GPS，會得到 ±120 公尺誤差）。
2. **段② 的節奏被壓縮。** 原場景 20s，為符合 10s 分鏡做了分段線性重映射（3.7 / 3.2 / 3.1 秒），「一栋一栋画框」只跑到 3/9 就被切到數字節拍——這是刻意的「永遠標不完」感覺，但確實比原設計緊。
3. **段⑤ 尾段（1:11–1:15）畫面是普查資料庫與系統診斷面板**，資訊密度高但視覺較平。
4. **段① 地圖段與圖卡之間只有一次 0.9s 交叉溶解**，段與段之間其餘都是硬切（各段自己都有淡入淡出，讀起來是刻意的節拍切換）。
