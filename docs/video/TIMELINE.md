## 主要技术决策

| 段落 | 技术 |
|---|---|
| ① | 真站生产建置（4173）逐帧控制相机；真站 viewer 载入真实 GLB |
| ②③④⑦ | Canvas 2D 程序化算图，**决定性**（同一帧索引永远画出同一画面，可重跑） |
| ③ 三维 | 自写迷你 3D 引擎：look-at 视图矩阵 + 针孔投影 + 深度排序点绘制；不用 three.js |
| ⑤⑥ | Puppeteer 驱动真站 + `requestAnimationFrame` 逐帧推进真站自己的卷动动画 + 逐帧截图 |
| 字幕 | HTML 字幕层烧进画面（不是 ffmpeg drawtext），排版可控、可精确遮罩出无字幕版 |
| 编码 | `h264_nvenc -preset p7 -cq 16`（本机 ffmpeg build **没有 libx264**；实测 nvenc PSNR 57.8 dB 优于 libopenh264 50.1 dB） |
