# 定位與建築確認更新

本次更新作用於建築辨識工作台。拍攝者位置與照片中的建築位置分開保存；未確認建築位置時，建築座標留空，定位紀錄不代替建築座標。

## 操作

1. 現場照片可點「取得定位」；歷史照片直接標記建築。
2. 點「在地圖上確認這棟建築」，載入現有離線建築輪廓，放大後點選。金色點與高亮輪廓表示使用者所選建築；藍點和估計圈表示裝置位置。
3. 使用位置輔助前確認該位置對應目前照片。已標記建築時用建築位置，否則用有效的裝置位置。
4. 同頁比較僅圖像與圖像＋位置的首位候選。相似度保持原值，位置輔助不自動消除視覺歧義。
5. 換照片或切換建築區域時清除位置確認；重新取樣不覆蓋已標記的建築。

## 精度與限制

- 瀏覽器沒有提供 GPS／WiFi provider，不再由精度和高度反推來源。
- 以 1/accuracy² 平滑座標；顯示範圍包住各有效讀數的回報誤差圈，不除以 √n，也不根據讀數跳動宣稱實際精度改善。設備回報的範圍不是實地測量保證。
- 裝置估計範圍大於 100m、缺失，或定位時間超過 5 分鐘時，位置輔助退回圖像。
- 拍攝位置的中性匹配範圍為 120m＋估計半徑；已確認建築位置為 30m 匹配容差。手動位置沒有測量精度值。
- 地理降權最大 0.08；不增加影像相似度。明顯位置衝突需要核對。
- 既有建築輪廓的資料誤差仍存在；點選輪廓不等於厘米級測量或自動識別。
- 本次沒有接入 RTK，也沒有測得定位或辨識準確率的提升。獨立實拍評估仍使用 tools/recognize/independent-eval.mjs 的固定門檻對照流程。

## 資料

SQLite schema v2 在原表加 location_role、footprint_id、capture_location、match_comparison；v1 自動升級，原編號、座標、R-Tree 保留。舊座標標示 legacy-unverified，不能由舊資料推斷已確認實際建築。

鏡射、SQLite、JSON 匯出分別保留建築位置、裝置位置、位置估計與圖像／位置候選對照。現有辨識參考庫沒有因本次定位更新自動擴大；普通建築新增參考照片的入庫與再次識別需另行接通。
