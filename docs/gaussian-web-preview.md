# 途见实时高斯实景

网站新增 gaussian.html。地图的大三巴详情提供“实景记忆 · 即时三维”入口；文化探索页面也提供入口。

功能：实时旋转、平移、缩放；自动环绕及交互暂停；恢复标定视角；显现动画；三档画质；手机双指缩放与平移；键盘方向键及加减键；本地打开高斯 PLY/SOG。用户选取的本地模型通过 Blob URL 在设备中读取，不上传服务端。

## 资源

本次示范直接使用实际大三巴重建 final.ply 的原始字节，657492 个高斯点，155169663 字节，完整三阶球谐系数。默认 scene.ply 与训练输出的 SHA-256 相同：d5955f72eaa5072f50fb71348a2cda47319defb0e27e732996fd8fa99b971f09。无降采样、无模型转换、无球谐阶数删减。早期16.6 MB有损试验文件不发布，也不作为默认资源。

在线大模型存储在 Sites R2，由同源 Worker 流式传输，支持 HEAD、单区间 Range 和 ETag。静态归档不包含大模型；发布时按原始字节分片上传并核对完整下载 SHA-256。临时初始化接口需要限时凭据，模型存在后禁止再次上传。默认高清渲染；渲染解析度设置仅调整画布像素比例，不改变模型点数或球谐阶数。

浏览器渲染仍使用 PlayCanvas 的原生 GPU 数据格式和排序、混合规则，不能宣称浮点运算完全无损或与桌面渲染逐像素一致；完整原始模型不代表重建缺失区域会自动变清楚。

相机来自这次完整 COLMAP 重建的 frame_000144.jpg，目标由对应图像的稀疏观测点计算。模型按照 PlayCanvas PLY 的坐标映射旋转 Z 轴 180 度；相机与目标使用同一映射。此局部坐标不等于地图地理坐标，因此使用独立实景视图，不直接覆盖地图建筑。

## 实现

PlayCanvas 2.21.4；优先 WebGPU，回退 WebGL2；使用 Unified GSplat。引擎负责加载、排序、投影和混合。网站实现交互、标定视角、生命周期管理及 GLSL/WGSL 显现效果。PLY 加载使用引擎的流式读取逻辑。
