# 途见本地共创记忆

作品：途见--基于3DGS与GMVR的澳门文旅记忆系统。

本次实现沿用现有 Vite、MapLibre、PlayCanvas 和建筑档案，新增本地 Node.js 24 / SQLite 服务。没有迁移现有框架，没有修改原始高斯模型。

## 启动

双击根目录 `啟動途見共創記憶.bat`。它启动记忆服务、导览服务和已构建的预览。首次运行先执行 `npm ci` 与 `npm run build`。

- 页面：`http://127.0.0.1:4173/memory.html`。
- 记忆服务：8790；导览服务：8787；前端：4173。
- 手动启动：`npm run memory:server`、`npm run guide:server`、`npm run preview`。
- 目前仅监听本机回环地址；手机远程访问及互联网多人服务需另行配置共享后端和 HTTPS。

## 已实现流程

1. 既有景点与建筑档案共用稳定编号。普通建筑可新增，座标可以待确认；读取设备位置只显示拍摄者位置参考，不自动写成建筑位置。
2. 故事支持文字、照片及原声。私人保存仅作者可读；公开投稿需确认素材使用权与录音者同意，经审核才公开。编辑已公开故事会返回待审核或私人状态。
3. 本地浏览器使用 HttpOnly / SameSite Cookie 身份。首个浏览器获得本机审核权限。此身份机制面向本机原型，并非互联网账号系统。
4. 录音最长三分钟；保留原声。点击转写时按约二十秒分段提交腾讯云 ASR；没有语音服务配置时仍可保存和播放录音。
5. 来源资料分事件、人物、主题和地点，要求名称、摘要与出处；现有种子来自已核对的澳门政府/文化局资料。没有虚构居民故事。
6. 将故事加入拼图后自动检索相关来源线索。AI 辅助解释由用户点击触发，使用后端 DeepSeek 凭据；缺少凭据时显示提示，本地检索可独立运行。AI 不创建已确认历史事实。
7. 拼图支持故事、来源资料和个人笔记，拖曳或按钮排序、备注、关系确认、保存、重新打开和 HTML 报告导出。
8. 探究活动支持一至六个地点、班级码、游前/游中/游后提交、教师查看和反馈。提交时保存拼图及引用资料快照，不随之后编辑改变。
9. 地图加入社区记忆点，随记忆点开关显示；重新获得焦点时读取新增地点和可读故事。
10. 高斯实景页支持采集版本选择、保存当前观察视角、关联故事及导出相机 JSON。视角切换约 0.7 秒缓动。局部观察视角不是地理测量定位。

## MacauSplat 接入

MacauSplat 主分支与 0.6 实验副本加入建筑记忆工程面板及 Tauri 接口，修改前备份位于本仓库 `output/integration/native-memory-backup/`。

独立工具 `tools/integration/memory-project.py` 亦安装为 MacauSplat 的 `scripts/memory-project.py`。它使用 Python 3.10+ 标准库，导出原始二进制 PLY、SHA-256、建筑编号、采集日期、来源、采集版本、观察视角与已有质量报告；不重新训练、不降采样、不修改重建文件。

桌面面板输入网站地点 ID 或建筑档案编号。没有提供相机时生成自动预览视角，需要在网站核对。可在网站实景页导出相机 JSON 后填入桌面面板。

网站选择对应地点 → 实景版本 → 导入记忆工程 → 选择 `manifest.json` → 选择 `scene.ply`。后端流式保存模型并核对 SHA-256，匹配后建立独立版本。导入错文件不会覆盖现有版本。

MacauSplat 工程新增 `memory-project.json` 旁车文件保存版本记录，已有旁车文件先备份；旧工程和原始 PLY 保留。

## 存储与导出

数据库和用户媒体位于 `output/memory-store/`，日志位于 `output/local-services/`，均被 Git 忽略。备份时保留完整目录，并先正常关闭服务。不要只复制 SQLite 主文件而遗漏 WAL。

资料导出是 JSON 清单，媒体原文件保留在本机服务目录。拼图及研学报告导出为可打印 HTML。当前没有自动云端发布或跨设备同步。
