# MacauSplat 标注优化与使用说明

## 已完成的改动

- 本机视频导入增加 M4V、AVI、MKV、WebM，保留 MP4/MOV。扩展名只决定文件选择范围，实际视频必须经 FFprobe/FFmpeg 读取。JPG/JPEG/PNG 图片序列仍要求同一分辨率。
- 浏览器界面的导入入口说明需要桌面应用，避免点击后无响应。
- 修正标注结果前后端字段：上轴来源为 `upSource`，后备轴风险为 `upAxisMayBeWrong`。未校准的尺寸使用重建单位。
- 生成 `review-quality.json`、`review-queue.html` 和 `seed-editor.html`。复核队列优先展示需复核影格，按相对于目标盒的视角分组，同时保留拒绝样本。
- 分级检查画面截断、近似相机模型、上轴后备值、有效支持点数、3×3 网格分布和点分布的二维跨度。阈值目前为启发式，候选标签仍需抽查。
- 少量人工目标框与 COLMAP track 对应。点需被至少两个种子影格实际观测，且不能与其他已观测种子框矛盾。缺失 track 不作为目标不存在的证据。
- 种子文件绑定当前重建的非密码学工程指纹，避免另一个工程使用相同影格名时误套框。相机/姿态/点/track 改变后需重新框选。支持不足直接报错，不悄悄退回整场景拟合。
- 清理用户可见的旧项目错误文案，修正包元数据；保留原许可证、NOTICE、第三方通知和上游来源。内部 crate、IPC header、着色器符号及应用标识维持兼容。
- 本构建不配置继承的遥测地址，新安装默认关闭统计；既有用户选择不被重写。未配置地址时不弹遥测邀请，仍可在设置中查看状态。
- 引擎 SHA256 校验增加 .NET 流式兼容实现，不跳过文件完整性校验。许可证检查同时要求衍生项目身份及上游署名。

## 桌面操作

1. 完成重建后点击“生成标注”，先得到初始框与复核文件。
2. 点击“查看目标框选文件”，在文件管理器中双击 `seed-editor.html`。
3. 选择至少两个不同视角，建议 3–5 个视角，框选同一个目标的可见范围；导出 `target-seeds.json`。
4. 返回桌面应用点击“用目标框生成标注”，选择导出的文件。
5. 双击 `review-queue.html` 查看复核原因，再结合 `qa.html` 检查框位。需要修改种子时重新框选并重跑。

种子框用于拟合目标，不能重复作为独立评测真值。初始框选页面展示有限个按风险与视角选出的影格；未显示的影格不代表无需检查。

## 命令行

```powershell
splatstudio fit-box "<project>" --out "<output>"
splatstudio annotate "<project>" --box-path "<output>/box.json" --out "<output>"
splatstudio fit-box "<project>" --seeds "target-seeds.json" --min-seed-support 2 --out "<target-output>"
splatstudio annotate "<project>" --box-path "<target-output>/box.json" --out "<target-output>"
```

## 验收与限制

前端 139 项与 Rust 205 项单元测试通过；前端生产构建通过。引擎 7 个锁定文件的 SHA256、COLMAP/Brush CLI 和许可证检查通过；SHA256 的 `abc` 已知答案测试通过。

273 张影格、44,011 个稀疏点的真实室内工程已验证拟合、投影、分级、网页筛选和种子框导出。两个通过界面拖曳生成的自动化测试框可以筛出 201 个多视角支持点并完成后续标注。该测试只验证流程，未定义建筑目标或独立人工真值，不能用于报告标注精度或识别提升。室内人物运动也不满足静态目标的理想重建条件。

目前没有语义分割、真实遮挡深度判断或像素级轮廓保证。三维盒可能仍包含邻近背景，部分视角上的可见二维框也不等于整个三维盒的投影框。候选／复核分级不改变原有 `accepted` 标签导出规则；训练前仍应检查并修正标签，低候选数不是准确率。

正式比较需使用澳门建筑数据，把用于约束的种子视角与独立人工质量评估分开，再用独立拍摄测试下游识别。分别记录人工时间、重建等待时间、框质量、漏标与误标。
