# 建築記憶點 · 重辨識評測報告

生成時間：2026-09-24 09:52　|　資料集：247 張影像

## 一、方法

1. **資料來源**：本專案 7 個 GLB 模型（5 棟建築 + 2 件文物）以 VTK 離屏渲染，每個模型 20 個視角（12 方位角 + 8 組跨條件）；另有 4 張既有「3D 地圖截圖」。
2. **取像分層**：`render-base` 同環境環繞；`render-cond/cond2` 改變仰角、距離與光照；`demo-map` 為地圖截圖；
   `demo-crop` 是舊流程用同張截圖裁切出的『第二張』，**主實驗排除**，只用於洩漏對照。
3. **相似度**：CLIP ViT-B/32 影像向量（L2 正規化）之餘弦相似度。
4. **判定**：相似度 ≥ 閾值視為同一棟（記憶點歸戶）。
5. **可重現性**：`python tools/eval/render_views.py && python tools/eval/build_dataset.py && python tools/eval/evaluate.py`，隨機種子固定為 20260923。
6. **範圍界定（重要）**：本報告的每一項指標都只衡量 **CLIP 影像嵌入**的重辨識能力。YOLO 僅用於物件偵測與隱私模糊，**不參與任何受測指標**；其實測結果另見 `tools/eval/out/yolo-check.json`（6 張測試圖中 1 張偵測到物件且類別錯誤，因人臉級聯在 OpenCV 5 不可用，已改用 YOLO person 模糊模式）。

## 三、結論與限制

- 受控條件下（同環境多視角）CLIP 影像向量能有效區分同棟／不同棟，閾值 0.86 的誤判率見上表。
- 跨條件（不同仰角、距離、光照）性能會下降，這正是實拍情境，也是需要 GPS 先驗輔助的原因。
- 渲染影像非真實照片：本報告的用途是**受控實驗**，真實世界的準確率需由實拍資料集驗證（見 `photos-src/real/`）。
- 樣本量限制：分類實驗（E6）實際類別僅涵蓋 3 類，僅作 sanity check，不能宣稱 12 類準確率。
