# 途見 60 秒宣傳片

本方案取代 40 秒版本。成片 60 秒，16:9、2560×1440、30 fps、繁體字幕；普通話與粵語兩版共用剪輯。

| 時間 | 畫面與操作 | 旁白 |
|---|---|---|
| 0–6 秒 | 大三巴實拍運鏡，銜接騎樓與唐樓街巷 | 澳門的記憶，不只在著名地標，也藏在我們每天走過的街巷。 |
| 6–17 秒 | 真實網站上傳照片，展示建築區域、候選、多照片核驗及位置確認 | 途見結合照片、地理位置與多視角線索，協助確認眼前建築。即使尚未收錄，也能確認地點、建立檔案。 |
| 17–29 秒 | MacauSplat 採集影格、COLMAP 相機位姿、Brush 訓練，銜接大三巴 3DGS 自由環繞 | 從多視角實拍到三維高斯實景，MacauSplat 保存建築的空間面貌，讓城市記憶可以再次走近。 |
| 29–43 秒 | 真實照片時間軸，保存文字與原聲，記憶拼圖與探究任務 | 照片留下歲月，原聲留下生活。居民與旅客把故事連回地點，學生透過線索完成探究，共同續寫澳門記憶。 |
| 43–55 秒 | Rokid 產品特寫、成年旅客佩戴體驗、真實小澳到點介紹，銜接小程序查詢與行程入口 | 透過 Rokid 觀看導覽、聆聽小澳；網站與小程序串連行程，讓文化探索從遊前延續到遊後。 |
| 55–60 秒 | 大三巴與途見品牌收束，顯示作品全名及網址／二維碼 | 途見。看見一座城，留下每一處記憶。 |

即夢生成大三巴實拍運鏡、Rokid 產品特寫、成年旅客佩戴體驗和手機街區銜接素材；生成的佩戴鏡頭標示體驗示意。網站功能與高斯模型使用實錄，文字及介面於後期製作。主要轉場 0.6–0.8 秒，重要操作結果停留至少 2 秒。Rokid 是觀看與聆聽載體，定位與照片辨識由連接端處理。

首次生成各鏡頭一個版本，沿用真實產品圖及實拍建築照片。即夢正式報價與需批准的積分上限在提交生成前確認，原 40 秒稿未提交生成，沒有已生成素材需要重做。
