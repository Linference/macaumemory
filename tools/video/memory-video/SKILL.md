# 途見建築介紹視頻 · 預設技能（Default Skill）

本檔是每次呼叫模型生成分鏡時都會載入的「預設技能」。它把途見的專業規則寫死，
讓不同的模型、不同的使用者輸入，都產出同一個品質標準的影片。
說明：本技能由 AI 程式助手（Claude）協助撰寫，規則須由作者審定。

## 一、三條底線（違反任何一條，分鏡作廢重做）

1. **旁白只講知識庫裡有的事。** 每一句旁白都必須列出它依據的說法編號（claims）。
   沒有編號支持的句子不能出現。標「推論」的說法，旁白要說「可以推想」；
   出處互相矛盾的地方，要把兩種說法都講出來；口述歷史要說明是「老街坊憶述」。
2. **畫面不改建築。** 真實模式只用真實照片做鏡頭運動；生成模式的提示詞只允許
   鏡頭與光線變化，必須寫明「建築結構、比例、裝飾保持不變」。
3. **誠實標示。** 片尾列出：資料出處、照片作者與授權、旁白為 AI 合成語音、
   生成鏡頭（如有）標「AI 生成畫面」。

## 二、敘事結構（建築片的四拍）

| 拍 | 作用 | 典型鏡頭 | 時長 |
|---|---|---|---|
| 1 立 | 建立整體印象：這是哪裡、第一眼看甚麼 | 全景，緩慢推近或上搖 | 5–7 秒 |
| 2 看 | 帶觀眾看一個關鍵細節 | 對準細節的推近 | 5–8 秒 |
| 3 解 | 解釋「為甚麼是這個樣子」（風格成因） | 由局部拉出或平移 | 6–9 秒 |
| 4 記 | 把建築連回人和城市：名稱由來、口述記憶、今日用途 | 環境或人流畫面，緩慢拉遠 | 5–8 秒 |

共 4–6 個鏡頭、總長 25–45 秒。第 2、3 拍可以重複一次（例如兩個細節）。

## 三、鏡頭語言（運鏡要對應建築內容，不是隨便動）

- **立面分層、柱式由簡而繁** → 由下而上的上搖（focus 從畫面下部移到上部）。
- **單一細節（浮雕、文字、徽章、滴水獸）** → 慢推近到細節，最後停 1 秒。
- **水平展開（迴廊、連續拱、街道）** → 橫向平移，方向跟隨建築的延伸方向。
- **建築與環境（依山、面海、與城牆相依）** → 由近拉遠，讓周邊入鏡。
- 縮放範圍 1.0–1.6；一個鏡頭只做一種運動；相鄰鏡頭避免同一方向重複。
- focus 座標以照片為準（0–1，左上為原點），必須落在照片中真的有該細節的位置。

## 四、旁白寫法

- 繁體中文書面口語，一個鏡頭 1–2 句，每句不超過 30 字；全片不超過 180 字。
- 第一句不要用「歡迎來到」「讓我們一起」這類套話；直接說一個具體的看點。
- 數字與年份最多 3 個；不用「最」「唯一」「全世界」等程度詞，除非知識庫原文就是這樣寫。
- 依訪客身份調整講法（見知識庫中的身份策略），但身份不能改變事實。
- 使用者提供的文字是「投稿者的描述／回憶」，不是已核實事實：要用時說「投稿者回憶……」。

## 五、生成模式提示詞（給圖生視頻模型，例如 Seedance）

按五段寫，缺一不可（即夢圖生視頻，首幀就是上傳的照片）：

1. **鏡頭**：一種運動，說清方向、起點與終點，例如「從下層緩慢向上搖，經過第二層壁龕，停在第三層中央」。
2. **主體**：照片中真的看得到的建築部位，用知識庫的名稱。
3. **環境動態**：只讓不屬於建築的東西動：雲、樹葉、行人、光影、浮塵。
4. **光線與質感**：天氣光線要和照片一致；統一用「寫實紀錄片質感」。
5. **約束句（必加，原文照抄）**：建築結構、比例、雕刻與文字完全保持原樣，不變形，不新增或刪除任何建築元素，鏡頭平穩無抖動。

例：`鏡頭從牌坊下層緩慢向上搖，經過第二層壁龕銅像，停在雕刻最密集的第三層中央；藍天白雲緩慢移動，石壁上的光影隨雲層輕微變化；午後側光，石材質感清晰；寫實紀錄片質感；建築結構、比例、雕刻與文字完全保持原樣，不變形，不新增或刪除任何建築元素，鏡頭平穩無抖動`

設定建議：16:9、5 秒、運動幅度低、關閉聲音（旁白另配）。

## 五之二、歷史短片模式（預設）

介紹視頻的主體是**講歷史**，不是拍現況：
- 依知識庫「年表」挑 3–4 個時間點，每個時間點一個文生視頻鏡頭重現當年；
- 最後一鏡用首尾幀，從歷史畫面過渡到今日實景照片；
- 提示詞寫明年代與場景，資料沒寫的細節（人物長相、起火原因、對白）用遠景剪影、煙霧、光影帶過；
- 一律加「人物為遠景剪影，無文字」；年份以剪輯字幕呈現，不讓模型寫字；
- 歷史鏡頭標「歷史意象重現 · AI 生成，非歷史影像」。

## 六、輸出格式（JSON，不可有其他文字）

```json
{
  "title": "片名（建築名＋一個看點，12 字內）",
  "shots": [
    {
      "beat": "立|看|解|記",
      "image": 0,
      "from": { "x": 0.5, "y": 0.7, "zoom": 1.0 },
      "to":   { "x": 0.5, "y": 0.35, "zoom": 1.25 },
      "narration": "旁白",
      "claims": ["f0", "w1"],
      "caption": "畫面角落的小字標註（可空）",
      "genPrompt": "生成模式提示詞"
    }
  ]
}
```
