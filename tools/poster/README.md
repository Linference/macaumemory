```powershell
cd 'D:\Users\LINKIT\Desktop\澳门记忆'

```

產出（`tools/poster/out/`）：

| 檔案 | 用途 |
|---|---|
| `澳門記憶_展板_A0.pdf` | **送印用**。A0 直式 841×1189 mm，文字與圖表皆為向量（圖表由 matplotlib SVG 轉入），作品圖帶為 1230px 寬（約 320 dpi） |

脚本每次執行都會印出 `[layout] 內容底部 y = … mm`，若顯示「溢出」代表內容超過頁面，需要壓縮區塊高度。

## 版面結構

1. 標題帶（深藍）＋ **作品畫面圖帶**（8 張系統截圖，自動從 `preview/` 挑選與裁切）＋ 右上 QR code
2. 研究問題 Research Question ／ 三個創新點 Innovation
3. ① 方法：從一張照片到一個永久記憶點（6 步流程圖）
4. ② 結果（一）：ROC 曲線 + 相似度分布 + 四個大數字
5. ③ 結果（二）：閾值取捨表 + 誤判來源分析（路氹城度假村群）
6. ④ 資料來源與研究誠信（render / demo-map / demo-crop / real-phone 四類）
7. ⑤ 限制與下一步
8. 頁腳：可重現指令 + repo + 線上網址

## 送印注意事項

- **務必 100% 原尺寸輸出**，不要選「fit to page」，否則比例會跑掉。
- 建議材質：霧面 PP 膠片或相紙 + 啞膜（展場燈光下不反光）；也可輸出成布展板。
- 若店家最大只到 A1：可用 A1 印（縮至 71%），正文仍有約 18pt，1 公尺外可讀；但 A0 效果最好。
- 安全邊距 24 mm，重要內容都在邊距內；QR code 尺寸 58×58 mm，實測 30 cm 外可掃。
- 若需要裁切線／出血，請告訴我，我再加一版。

## 要改內容時

| 想改什麼 | 改哪裡 |
|---|---|
| 圖帶放哪幾張畫面 | `build_poster.py` 的 `prefer=[...]`（檔名對應 `preview/`） |
| 版面區塊高度 | 各區塊的 `bh / fig_h / sh / prov_h / lim_h` 常數 |
| 字級 | 檔頭 `S_TITLE / S_SECTION / S_BODY …` |
| 配色 | 檔頭 `INK / GOLD / TEAL / RED` |
| 數據 | 跑完 `tools/eval/evaluate.py` 後重新執行本脚本即可（圖表會更新） |

## 待補（實拍照片到位後）

實拍資料集（`photos-src/real/`）完成後，建議把展板升級為：
1. 結果（一）換成 **實拍版 ROC / 分布圖**（同一套脚本自動產生）；
2. 圖帶加入 2~3 張學生實拍照（並在 ④ 標明為 real-phone）；
3. 加一格「渲染 vs 實拍」的域偏移對照小圖。
