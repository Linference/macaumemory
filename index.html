即時巴士報站 API

澳門官方實時報站沒有公開且允許跨網域的 API。若你有 data.gov.mo 的 API Key，或自建了代理（例如 Cloudflare Worker，範本見 worker/bus-proxy.js），把可回傳 JSON 的網址填在這裡，網址中用 {stop} 代表站點 ID、{name} 代表站名。

回傳格式支援：[{"route":"9A","eta":"3 分鐘"}] 或含 eta/min/route 欄位的陣列。設定只存在你的瀏覽器。

設定 DeepSeek API Key（只存在你的瀏覽器，不會上傳到本站）
